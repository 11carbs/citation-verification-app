# 真實論文配對稽核（更新：2026-11-27）

本次使用研究資料夾 `5篇` 中五份本機 PDF，執行 `scripts/audit_real_papers.py`。這是解析與配對的功能檢查，**不是人工標註的正確率評估**；`matched` 只表示找到唯一的 ref 條目，仍須人工檢查內容與來源身分。

修正並重新檢查的錯配來源：

- 雙欄 PDF 先讀完左欄再讀右欄，減少正文與 ref 交錯。
- 辨識 `Bibliographical References`，並處理 ACL 風格的 `作者. 年份.` ref。
- 處理獨立一行的數字編號；避免把年份或 DOI 網址片段當成新 ref。
- 從重複頁首排除期刊名稱與年份；在附錄前停止讀取正文的參考文獻，避免把附錄範例誤當本篇 ref。
- Phantom citations 的跨行作者清單與下一行年份已分成獨立書目；`van Rensburg` 這類複合姓氏跨行引用可對應；文中 `(1)`、`(2)` 是流程列舉，`(RAAISA 2024)` 是會議名稱，均不再列為引用配對；文末 `How to cite this article` 不算該篇的參考文獻。

仍待處理：

- CiteScreener 有論文內的表格／資料集範例引用（如 `[69]`），其來源不在本篇 ref 清單；目前列為待人工檢查，不能據此說本篇缺少真實文獻。
- SciCiteVal 的部分作者年份引用與跨行姓名仍無法安全對應；需要對 PDF 版面及 ref 條目做人工核對。
- SemanticCite 是數字型 ref，但正文偶有作者年份提及；現階段不憑姓氏猜測對應。
- PDF 多欄、表格、註腳與掃描文字仍可能遺漏；`matched` 不代表內容支持，需由後續來源檢索與人工標註驗證。
